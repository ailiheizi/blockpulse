# BlockPulse · 区块预言家

红黑绿预测、有限行动和两个规则 Bot 的浏览器玩法原型。所有区块、积分和结算在浏览器本地模拟；无钱包接入、无链上部署，积分不可兑换。

## 双击试玩（首选）

在访达中打开本项目文件夹，双击根目录的 **`本地试玩.html`**，即可在浏览器试玩。这个单文件已内联网页样式和脚本，无需 Node.js、终端或本地服务器，也不需要上传项目。

注意打开的是项目根目录的 `本地试玩.html`；开发源码目录中的 `dist/index.html` 使用 JavaScript 模块，不能用相同方式直接双击运行。修改源码后可运行 `npm run build:local` 重新生成单文件。

## 本地开发服务（macOS，可选）

需要开发或通过 HTTP 试玩时，双击 **`启动试玩.command`**。启动器会打开终端，并自动用浏览器访问 [本地开发试玩](http://127.0.0.1:4173)。如果 4173 上已有本项目的服务，会直接复用，不会重复启动。

**提供服务的终端窗口必须保持打开。** 关闭该窗口或按 `Control+C` 会停止本地服务；网页之后就无法访问。再次双击启动器即可重开。若提示复用了已有服务，应保留原来提供服务的终端；新开的提示窗口可以关闭。

启动器会寻找已安装的 Node.js 18 或更新版本，也会尝试本机已有的 Codex 运行时；不需要 `npm install`，不会下载依赖、上传项目或部署云端站点。服务只监听本机 `127.0.0.1`。

也可以在终端执行（路径含空格，需保留引号）：

```sh
cd "/Users/macos/Documents/temp 2/blockpulse-demo"
./启动试玩.command
```

如果终端已能执行 `node`，也可在项目目录运行 `node server.mjs` 或 `npm start`，然后手动打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。不要直接双击 `dist/index.html`，浏览器的本地文件限制可能使 JavaScript 模块无法运行。

打不开时先查看终端：若提示缺少 Node.js，说明系统命令和本机运行时都不可用；启动器不会自动安装。若提示端口占用，启动器会保留现有进程，请确认原服务的地址与状态。网页刷新无效时，先确认服务终端仍然打开。

## 玩法

1. 玩家与动量、回归两个 Bot 各有 1,000 积分。选择红（最终热度大于 100）、黑（小于 100）、绿（等于 100），投入 20、50 或 100 积分。
2. 开始后封盘，15 秒内每人最多使用 3 张行动券加热 +1 或降温 -1，也可以保留不用。热度初始 100；模拟区块每 500 毫秒推进。
3. 命中者按下注占比分配所有锁定积分，到账包含本金。无人命中原额退款；整数尾差按最大余数法确定分配。所有参与者的可用积分与锁定池之和始终为 3,000。
4. 可继续下一轮或重置；浏览器尽力保存当前进度。Bot 使用种子计划且遵守同样的最多三次行动限制，不读取未来输入。

## 测试

```sh
npm test
```

测试覆盖封盘、行动券、积分守恒、整数分配、无人命中、重复结算、模拟步长一致性和多轮边界。

## 范围

该原型用于检验可理解性和游戏手感，不是概率公平或策略平衡的证明。绿色发生概率由玩家和 Bot 的行动共同决定。没有真实期货、杠杆、随机预言机、真实资产或公开多人联机。`dist/game.js` 是纯逻辑，`dist/app.js` 是界面和本地计时。使用系统字体，没有外部字体请求；单文件可离线试玩。
