# BlockPulse · 链上交易竞技游戏原型

与策略 Bot 同场买卖红、黑、绿结果份额，用有限行动影响热度，在持有到期与提前退出之间选择。v2 加入实际买卖、动态报价、持仓与成本、收益预览、概率说明和本地策略繁忙模式。

交易与结算仍是本地浏览器模拟，现已加入可选的 Monad 测试网接入：连接浏览器钱包、切换测试网、读取 MON 余额和真实区块。钱包 MON 与模拟积分分别展示，当前没有链上合约、真实多人或资产兑付；成交频率来自本机模拟，不代表 Monad 链上 TPS，模拟随机也不具备链上随机源的安全保证。

页面资源使用本地文件和系统字体，不加载外部 SDK。只有主动连接钱包或点击“读取测试网”才会读取链数据；不使用这些功能时，本地交易仍可离线试玩。

## 直接试玩

双击项目根目录的 **本地试玩.html** 即可离线体验交易。样式和脚本全部内联，无需 Node.js、终端、安装依赖或上传项目。钱包扩展通常需要 HTTP / HTTPS 页面才能注入，测试钱包接入请使用下面的本地服务。修改源码后用 `npm run build:local` 重新生成单文件。

通过本地 HTTP 开发时，macOS 可双击 **启动试玩.command**。它会复用已运行的本项目服务，或使用系统 Node.js / 本机已有的 Codex Node.js 运行时启动，再打开 [本地试玩](http://127.0.0.1:4173/)。提供服务的终端必须保持打开，按 Control+C 才停止；不安装依赖、不关闭其他进程、不发布站点。

也可以在终端运行：

```sh
cd "/Users/amigoer/DevProjects/blockpulse-demo"
./启动试玩.command
```

终端已配置 Node.js 18 或更新版本时，可运行 `npm start`。服务只监听 `127.0.0.1:4173`。`dist/index.html` 使用模块，需通过 HTTP 运行；可直接双击的是项目根目录的 `本地试玩.html`。

## Monad 测试网接入

1. 在支持 EVM 的浏览器钱包中打开本地 HTTP 页面，选择要连接的钱包并授权账户。支持 EIP-6963 多钱包发现，也兼容传统 `window.ethereum` 注入。
2. 若当前网络不匹配，点击“切换到 Monad Testnet”。仅在钱包提示未添加该网络时请求添加，添加后再次切网并核对实际链 ID；拒绝请求不会影响本地游戏。
3. 连接步骤会标明账户、网络和余额是否就绪。连接后可单独“刷新余额”、查看读取时间、复制地址或打开地址浏览器；剪贴板不可用时会展开可手动复制的完整地址。切换账户或网络会清除旧余额并重新读取；断开本站连接后不再跟踪该钱包，扩展中的网站授权仍需在钱包内管理。
4. 无需钱包也能点击“读取测试网”，先核对 RPC 的链 ID，再读取最新区块、高度、区块时间和 RPC 请求耗时。成功后每 5 秒采样一次，保留最近 6 个不同区块的快照；这不是连续区块列表，也不是链上 TPS。切到后台或浏览器离线时暂停，返回或联网后恢复；读取失败则停止自动重试，保留旧数据并标明非实时状态，可手动重试或暂停。
5. 收起接入面板会暂停区块读取，让出交易空间；再次展开不会自动恢复读取。没有钱包、钱包不支持自动添加网络时，可展开“手动添加网络 / 连接帮助”，查看网络参数并复制 RPC。
6. 需要测试币时，可打开 [Monad 官方水龙头](https://faucet.monad.xyz)。MON 不会兑换为游戏积分。

| 配置 | 值 |
| --- | --- |
| 网络 | Monad Testnet |
| Chain ID | `10143` / `0x279f` |
| 原生测试币 | MON，18 位小数 |
| 公开 RPC | `https://testnet-rpc.monad.xyz` |
| 区块浏览器 | [Monadvision Testnet](https://testnet.monadvision.com) |

网络参数依据 [viem 官方链定义](https://github.com/wevm/viem/blob/main/src/chains/definitions/monadTestnet.ts)，浏览器使用其原浏览器域名重定向后的 Monadvision 地址；钱包接入参考 [Monad 官方说明](https://docs.monad.xyz/guides/add-monad-to-wallet/testnet)。公开 RPC 可能限流或不可用，面板会显示失败，本地模拟可继续。

当前只请求账户授权、网络切换和链上只读数据，不请求消息签名或发送交易。钱包地址和余额不写入本地游戏存储；公开 RPC 只接收链 ID 与最新区块查询，余额查询通过用户选择的钱包完成。

钱包的每次只读状态请求有 8 秒超时，失败后可重试或断开重连；等待用户授权或确认切网的弹窗不受这个超时限制。迟到的请求结果不能覆盖新账户、新网络、暂停后的数据或重新读取的结果。区块采样和钱包余额刷新相互独立，刷新余额不会开启公开 RPC 轮询。

后续黑客松版本可以分三步推进：先把房间、回合、份额与订单规则放入测试网合约；再接入可验证的随机源和可验证结算；最后按房间隔离状态，测试多房间并发与实际链上吞吐。前三者都需要真实合约、资金账本和网络测试，本次接入先建立可演示的钱包与链状态入口。

## 一轮怎么进行

1. 选择普通场（2 个 Bot）或繁忙场（20 个 Bot）。更换模式会重置场次与资金。
2. 每名参与者获得 1,000 模拟积分，另有独立做市账户初始储备 1,000；这些储备是真实记账的模拟资金。
3. 开始后共 60 秒，前 55 秒可以买卖、加热或降温；最后 5 秒封盘，交易和控场均停止。
4. 红色表示最终热度大于 102，黑色小于 98，绿色在 98 至 102 之间（含端点）。命中份额每份兑付 1 积分，其余兑付 0。持仓也可在封盘前提前卖出。
5. 每人每轮最多 3 张行动券，使用一张使热度 +1 或 −1。普通交易只改变报价和持仓，不直接改变热度。
6. 封盘后结算时加入本地模拟的整数环境扰动。范围是 ±（参与人数 × 3 + 3），覆盖全体可能的行动影响，避免合法行动把某个颜色变成必胜结果。它演示概率机制，不是可靠的链上随机源。
7. 结算后可继续下一轮，保留积分和累计表现；重置会恢复全部初始资金。

## 报价、收益和概率

市场使用三结果 LMSR 自动做市，价格随真实模拟订单变化。初始三个价格均为 1/3，价格之和为 1。价格不是游戏胜率：热度与环境扰动产生的“情景概率”单独计算，并假设后续没有人继续行动。

买入或卖出 1–1,000 整数份额，不能卖空或加杠杆。报价显示平均成交价、价格影响、0.3% 手续费、支出或到账；买入预览还显示命中兑付、命中净收益与收益率。全部份额不会同时按屏幕上的边际价格成交。

例如 100 份红色若平均成交价为 0.40，未计费用的成本是 40；红命中兑付 100，净收益 60。若提前以平均 0.65 卖出，未计费用的到账是 65。真实预览与记账还会扣除费用和考虑价格随数量变化。

市场账户承担做市盈亏并持有兑付资金。执行订单前核对余额、库存与兑付能力；无可接受报价时拒绝订单，不能承诺任何数量、任何时刻都能固定价格退出。每一笔交易和结算都保持参与者现金与做市现金总和守恒。份额是对这些储备的条件索取权，不能重复当作现金相加。

持仓采用平均成本计算已实现盈亏。账户净值与未实现盈亏按当前市场逐笔清仓估算，考虑价格影响和卖出费用，避免把自身买入抬价直接当成可兑现盈利；之后的交易和行情仍会改变结果。持仓明细中的市价估值若使用边际价格会另外标注。最大回撤使用相同清仓估值口径，未做盈利或策略平衡保证。

## Bot 和繁忙模式

动量 Bot 观察历史价格和当前趋势，概率 Bot 比较情景概率与市场报价。它们实际支付资金买入、卖出持仓、缴纳相同费用，并遵守余额、库存、封盘和行动券限制。策略不读取未来结算结果。

繁忙场运行 20 个本地策略账户，展示成交记录、持仓、盈亏和本地成交频率。浏览器按确定的模拟时序处理事件；它不是实际并行链上负载，也没有公开多人联机。利用 Monad 并行执行的多房间合约设计和真实网络基准测试属于后续工作。

## GitHub Pages 配置

已按用户授权启用 [Pages 自动部署工作流](.github/workflows/pages.yml)：每次推送 `main` 自动执行 `npm test`，测试通过后打包静态资源并发布到 [GitHub Pages](https://ailiheizi.github.io/blockpulse-demo/)。测试失败时停止发布，线上保留上次成功版本；也可在 GitHub Actions 中手动运行该工作流。

## 验证与文件

```sh
npm test
npm run build:local
```

- `dist/game.js`：不可变状态更新、做市报价、资金账本、策略、时间与结算。
- `dist/app.js`：界面、本机计时、浏览器进度保存；v2 使用新存储版本，旧版进度不沿用。
- `dist/index.html` / `dist/style.css`：页面与本地系统字体样式。
- `dist/monad.js`：测试网参数、钱包状态、多钱包发现、只读 RPC 与错误处理。
- `dist/monad-monitor.js`：区块采样、取消与去重、后台和离线暂停、手动恢复及清理。
- `dist/monad-ui.js` / `dist/monad.css`：Monad 接入面板、按需轮询与响应式样式。
- `tests/game.test.mjs`：交易、库存、费用、资金守恒、兑付、封盘与多轮边界测试。
- `tests/monad.test.mjs`：钱包授权、切网、事件清理、异步竞态及 RPC 数据校验、取消和超时测试；使用模拟 provider，无需扩展或真实资产。
- `tests/monad-monitor.test.mjs`：并发读取去重、暂停和恢复、采样上限、错误恢复与销毁测试；使用可控的定时器，不访问网络。
- `scripts/build-local.mjs`：生成不需要服务的单文件试玩。

存储不可用时仍可试玩；浏览器会尽力保存进度，关闭标签页期间不保证模拟继续运行。当前原型用于检验交易和控场的可玩性，尚未做策略平衡、安全审计或链上能力验收。
