# BlockPulse · 事件预测交易竞技场

> 一分钟一局：判断红、黑、绿哪种结果会发生，买入结果份额，盘中卖出锁定盈亏，或持有到期等结算。

- **在线试玩**：<https://ailiheizi.github.io/blockpulse/>（无需安装、无需钱包即可开玩）
- **源码仓库**：<https://github.com/ailiheizi/blockpulse>

## 一、项目简介

BlockPulse 把预测市场做成了一分钟一局的竞技游戏。每轮先公布事件和红、黑、绿三种结果的命中条件，玩家用积分或 Monad 测试网 MON 买入结果份额。前 55 秒自由交易，最后 5 秒封盘，命中份额每份兑付 1，未命中兑付 0。

价格不是固定赔率，而是由自动做市根据真实订单实时变化。玩家既可以押中结果持有到期，也可以低买高卖、提前退出。比拼的不只是猜对结果，还有入场价格和退出时机。每轮按净盈亏排名，提前退出收益、到期兑付和全部手续费都计入成绩。

## 二、为什么做

- **预测市场门槛高**：多数产品周期长、规则复杂，新用户难以在几分钟内理解“价格就是市场共识”。BlockPulse 把一个完整的交易闭环压缩到 60 秒，边玩边懂。
- **链上事件天然可核验**：区块高度、交易笔数都是公开数据，任何人都能在区块浏览器核对结果，适合做公平、透明的结算来源。
- **高频玩法需要高性能链**：一局 60 秒内会产生大量报价更新和成交，Monad 的出块速度和低手续费让这类高频互动在链上成为可能。

## 三、核心玩法

1. **选结果**：看清本轮事件，以及红、黑、绿三种结果的命中区间。
2. **看报价**：输入预算或份数，下单前预览实际成交份数、平均成交价、价格影响、0.3% 手续费、命中兑付和收益倍数。
3. **下单交易**：买入 YES，或做空 / 买 NO（押某个结果不会发生）；持仓可以随时卖出或平仓。
4. **有限控场**：每人每轮 3 张行动券，可加热 +1 或降温 −1。行动的影响有上限，任何人都无法靠用券锁定结果。
5. **结算复盘**：封盘后按事件结果兑付，展示结果依据、收盘记录与净盈亏排名。

## 四、主要功能

| 功能 | 说明 |
| --- | --- |
| 实时价格发现 | 三结果 LMSR 自动做市，每一笔成交都会改变报价，三色价格之和恒为 1 |
| 完整交易方式 | 买入 YES、做空 / 买 NO、卖出持仓、平 NO；支持按预算或按份数下单，同预算对比三色收益倍数 |
| 无杠杆风险 | NO 为全额支付的两腿组合，没有借贷、杠杆或强平；资金守恒，每一笔都可追溯 |
| 策略 Bot 同场 | 普通场 2 个、繁忙场 20 个动量 / 价值策略 Bot，实际出资、缴费、记账，不读取未来结果 |
| 玩家自己的量化 | 可开启价值 / 动量策略，用自己的余额自动交易，并展示每次决策理由与成交 |
| 真实区块事件 | “忙区块”玩法按 Monad 测试网真实区块数据结算，封盘与结算按区块号推进 |
| 链上 MON 交易 | 连接钱包，用测试网 MON 与链上 LMSR 市场合约直接交易，买卖与兑付由合约完成 |
| 钱包与测试币 | 支持 EIP-6963 多钱包发现、一键切换 Monad Testnet、汇总官方与第三方水龙头 |
| 体验细节 | 深浅主题切换；纯静态页面，不加载外部 SDK；单文件即可离线试玩 |

## 五、Monad 集成

**1. 真实忙区块事件（只读链上数据，无需钱包）**

- 事件：开场后统计接下来 180 个区块中，交易数不少于 3 笔的“繁忙块”数量 X。
- 基准 B：取开场前最近 600 个区块的繁忙比例乘以 180，开场时固定并公开展示。
- 结算：收盘分数 = 100 + 行动让分 + (X − B)，高于 103 为红、低于 97 为黑、其余为绿。行动让分最多 ±3，不会改变链上实际数据。
- 第 165 个区块封盘、第 180 个区块结算，每个区块号和交易数都能在 Monadvision 浏览器核对。
- 开盘价取模型先验概率，此后每个新区块都会重新估算，行情随成交与新区块共同变化。
- 数据中断时本轮作废，未平仓份额按含费成本退回，已平仓的盈亏保留。

**2. 链上 MON 市场合约**

- 合约 `BlockPulseMarket.sol` 是共享的三结果 LMSR 市场：每份命中兑付 0.001 MON，手续费 0.3% 留在做市储备，单笔 1–1,000 份。
- 开局时登记一个约 57 秒后的区块，结算噪声取自该区块的哈希；做市储备始终覆盖所有可能的兑付。
- 页面内可直接用钱包部署新市场，或粘贴已有合约地址。页面会比对链上代码与内置合约，完全一致才使用；还可以复制分享链接，邀请他人进入同一个市场。
- 买入设置 3% 价格保护，未用部分当笔退回；卖出设置 3% 最低到账保护。

**3. 钱包与网络**

- 网络：Monad Testnet，Chain ID `10143`，公开 RPC `https://testnet-rpc.monad.xyz`。
- 支持 EIP-6963 多钱包发现，兼容 `window.ethereum`；可一键添加并切换网络、查看余额，实时采样最新区块与 RPC 延迟。

## 六、技术实现

- **前端**：原生 JavaScript ES Modules + CSS，无框架、无外部 SDK、无构建依赖；游戏引擎为纯函数式的不可变状态更新。
- **做市与账本**：LMSR 报价、库存与兑付能力检查，参与者与做市账户资金总和守恒。
- **链上数据**：按批次限速读取区块，保证区块连续，并处理失败、过期与取消。
- **智能合约**：Solidity 0.8.30 + Foundry，含 13 项合约测试。
- **质量保障**：100 项自动化测试，覆盖交易、费用、资金守恒、结算、钱包授权、RPC 异常与构建产物。
- **发布**：GitHub Actions 在推送 `main` 时自动测试，测试通过后打包成单个 HTML 发布到 GitHub Pages；测试失败则不发布。

## 七、如何体验

1. 打开在线试玩地址，选择“模拟积分”，再选择 2 位 Bot 或 20 位繁忙模式。
2. 点击“开始 60 秒交易”，选择颜色、输入预算后下单，观察价格曲线与 Bot 成交。
3. 想体验真实链上数据，切换到“真实 Monad 忙区块”事件；想用钱包交易，切换到“测试网 MON”，连接钱包并领取测试币。

本地运行：克隆仓库后双击 `本地试玩.html` 即可离线游玩，或执行 `npm start` 后访问 `http://127.0.0.1:4173`。

## 八、当前状态与已知限制

- 模拟积分和测试网 MON 都没有现实价值，两种模式账本独立，不构成任何收益承诺。
- 链上合约的随机数取自区块哈希，出块者可以施加影响，仅适合测试网演示，后续需接入可验证随机源。
- 忙区块事件目前在浏览器内结算，尚未上链；外部脚本发交易可能抬高繁忙块数。
- Monad 储备余额规则是否适用于合约账户尚未在真实测试网验证，余额低于 10 MON 的市场合约在卖出或领取时可能回滚。
- 20 个 Bot 运行在本地浏览器中，不代表链上吞吐；目前尚无公开多人房间。
