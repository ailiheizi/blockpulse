# BlockPulse · 区块预言家

红黑绿预测、有限行动和两个规则 Bot 的浏览器玩法原型。所有区块、积分和结算在浏览器本地模拟；无钱包接入、无链上部署，积分不可兑换。

## 启动

无需安装依赖。使用 Node.js 18 或更新版本运行：

```sh
npm start
```

浏览器打开 http://127.0.0.1:4173 。也可以用任意静态服务器提供 `dist/` 目录。

## 玩法

1. 玩家与动量、回归两个 Bot 各有 1,000 积分。选择红（最终热度大于 100）、黑（小于 100）、绿（等于 100），投入 20、50 或 100 积分。
2. 开始后封盘，15 秒内每人最多使用 3 张行动券加热 +1 或降温 -1，也可以保留不用。热度初始 100；模拟区块每 500 毫秒推进。
3. 命中者按下注占比分配所有锁定积分，到账包含本金。无人命中原额退款；整数尾差按最大余数法确定分配。所有参与者的可用积分与锁定池之和始终为 3,000。
4. 可继续下一轮或重置；浏览器尽力保存当前进度。Bot 使用种子计划且遵守同样的最多三次行动限制，不读取未来输入。

## 测试

```sh
npm test
```

测试覆盖封盘、行动券、积分守恒、整数分配、无人命中、重复结算、模拟步长一致性和多轮边界。

## 范围

该原型用于检验可理解性和游戏手感，不是概率公平或策略平衡的证明。绿色发生概率由玩家和 Bot 的行动共同决定。没有真实期货、杠杆、随机预言机、真实资产或公开多人联机。`dist/game.js` 是纯逻辑，`dist/app.js` 是界面和本地计时。网络字体不可用时自动回退到系统字体。
